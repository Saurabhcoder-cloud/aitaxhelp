# AI Governance & Compliance Architecture

**Platform:** TaxAIHelp ([taxaihelp.com](https://taxaihelp.com))  
**Standard:** Zero Math Hallucination & Deterministic Separation  

---

## 1. Primary Invariant: Zero Math Hallucination Policy

Under no circumstance is Google Gemini or any Large Language Model permitted to:
1. Calculate tax liabilities, deductions, self-employment tax, or quarterly estimates independently.
2. Override or modify the numerical output generated by the deterministic Tax Engine (`tax-engine/`).
3. Invent, interpolate, or extrapolate tax rules for unsupported or future unannounced tax years.
4. Provide formal, binding legal or certified public accounting (CPA) advice.

All monetary amounts presented to taxpayers originate exclusively from the deterministic, integer-cent Tax Engine.

---

## 2. Intent Extraction vs Explanation Pipeline

The interaction with Gemini is strictly divided into two non-overlapping, server-side phases:

```
[Phase 1: Structured Intent Extraction]
User Query → Gemini NLP Prompt → Structured JSON Entities (w2Wages, 1099, expenses, filingStatus, taxYear)
  ↓
[Phase 2: Strict Validation]
Parsed Entities → Zod Schema Runtime Guard (`tax-engine/validation/schemas.ts`)
  ↓
[Phase 3: Deterministic Tax Engine Execution]
Validated Inputs → Pure Functional Tax Engine (`tax-engine/`) → Verified Integer-Cent Result
  ↓
[Phase 4: Educational Translation & Explanation]
Verified Result + User Query → Gemini Plain-English Summarizer → Structured Markdown Explanation
  ↓
[Phase 5: UI Presentation]
Engine Verified Numbers + Transparent Breakdown + Educational Summary + Disclaimers
```

---

## 3. Strict Compliance Guardrails

The Gemini system instructions (`lib/ai/gemini/prompts.ts`) enforce these non-negotiable compliance rules:

1. **No IRS Affiliation:** Explicitly prohibited from claiming or implying IRS affiliation, endorsement, sponsorship, or certification.
2. **No Guaranteed Outcome:** Strictly barred from claiming guaranteed refunds, maximum tax avoidance, or 100% audit-proof returns.
3. **No Unapproved Rules:** Prohibited from applying non-statutory rules, experimental tax credits (CTC/EITC/EV), or unsupported state tax deductions.
4. **Mandatory Educational Disclaimers:** All conversational responses must reinforce that TaxAIHelp provides educational estimates and does not replace consultation with a licensed CPA, Enrolled Agent (EA), or tax attorney.

---

## 4. Key Management & Server Boundary

- `GEMINI_API_KEY` is strictly an internal, server-only secret. It must never be prefixed with `NEXT_PUBLIC_` and is never bundled into client-side JavaScript.
- All AI operations execute within server Route Handlers (`app/api/v1/ai/assistant/route.ts`).
- When `GEMINI_API_KEY` is not present, the system defaults to a deterministic heuristic mock pipeline, ensuring the platform remains fully functional in local development without network failures or runtime crashes.
